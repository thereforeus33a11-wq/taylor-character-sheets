# Taylor Character Sheets (v7)

Corrected character design reference pack for **Taylor** (blonde delivery courier from the source comic).

## What's corrected in v7
- **Lean athletic body proportions** (slimmer thighs/legs, runner/courier build)
- **Dense freckles** on face, shoulders, and upper buttocks
- **Bikini tan lines** on midriff
- **Pale soles** (palmoplantar hypopigmentation) vs tanned tops of feet
- **Correct clothing**: white JIM'S crop top, tiny blue denim low-rise shorts, red gloves/headband/backpack straps, black choker, bandages
- **Natural hair tuft** peeking above shorts waistband
- **Under-shirt jewelry outlines** visible through crop top fabric
- Navel jewelry with red bead
- Same western comic cel-shaded art style
